# game shopping app

## 🎯 Project Overview
This project is a game shopping app that makes it easier to find Steam games based on what you're actually looking for.

Instead of searching through hundreds of games individually, users can filter by game type, ratings, platform compatibility, pricing, and available demos or bundles to find games that match their preferences.

## ✨ Key Features
### Planned MVP Features:
- Search games by category or Steam tags.

- Filter by positive review rating (default 87%+).

- Filter by platform: Windows, macOS, or both.

- Identify available demos and prologues.

- Identify bundle availability (Yes/No).

- Display game information, including:

    - Steam App ID

    - Game title and image

    - Positive review percentage and review count

    - Platform compatibility

    - Individual game price

    - Demo/prologue and bundle availability
